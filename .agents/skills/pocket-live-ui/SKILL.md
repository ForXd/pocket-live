# Pocket Live Android 界面

从当前页面及共享组件入手。主题在 Theme.kt，按钮、加载环与导航项在 GlassControls.kt；后者保留了历史文件名，当前材质是实色平面。

## 页面和操作

- 用黑白灰表达正文、背景、选中和禁用状态。豆瓣评分徽标使用金色星形和白色分数，保留封面原色，错误及资源可用性同时用文字说明。底部选中项通过图标对比度、标签字重和轻微阴影区分。阴影和实色圆角背景共用同一轮廓，切换确认后才显示。
- 手机底栏为实色圆角浮栏，首页、历史、订阅、设置四项等宽，图标在上、标签在下。浮栏与内容共用 20dp 左右边距，系统导航安全区留在外侧，列表末项可滚到浮栏上方。宽屏使用侧栏。避免引入折射、高光或独立滑动选中底板。
- 首页推荐、分类卡片固定两列，头图和栏目标题跨列。横向作品卡的封面与正文顶部对齐，加载占位与成图共用裁剪边界。检查长标题、展开来源和大字号。
- 搜索与历史沿用同一搜索框样式，胶囊外层绘制阴影，清除和提交图标居中。图标动作保留 48dp 触控区。历史左滑露出删除图标，点击后确认。
- 用共享平面按钮表达同类动作。未知时长的等待用 PocketLoading 圆环；已有完成量时传入进度。播放时间轴和选集观看记录属于内容进度。选集在卡片背景表现进度，各状态的标题、次行及卡片边缘保持对齐。
- 手机操作、筛选和确认放在底部抽屉，全屏播放器使用侧抽屉。拖动时把手、边框和内容同步位移，松手后再回弹或关闭。

## 横屏播放器

唤起时间轴时顶部同时显示设备时间和电量，隐藏时一起收起。返回、片名和更多操作在上方。底部左侧依次为白色播放／暂停、上一集、下一集，右侧为选集和白色快速换源。快进快退沿用手势。全屏控制层使用透明背景，唤起时间轴时维持视频原有亮度。顶部、时间轴和底部操作各自占满安全区宽度，保留滑块端点和按钮触控所需空间。

## 模拟器复核

按改动范围从正常入口操作，检查日间、夜间、长标题、大字号和键盘出现后的布局。导航看快速连点切换，抽屉看慢拖、反向拖和松手，播放器看显示、隐藏、拖动、切集与返回。用截图核对静态边缘，用真实触摸验证动作。UiLayoutDeviceTest 提供首页与主要页面夹具，PlaybackGestureDeviceTest 覆盖横屏控制。需要人工验收时可用 UiLayoutDeviceTest 的 manualDesignReview=true 保持夹具运行。
