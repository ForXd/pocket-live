# Pocket Live Android 界面

从当前页面及共享组件入手。以方案 A 修订图册的同名页面为视觉基准，再与 Android 同一入口、同一状态的截图并排比较。Theme.kt 管理主题色，GlassControls.kt 提供共享按钮、加载环和导航控件。

## 页面和操作

- 烟晶黑配中性灰阶正文。设置、订阅和播放选项复用 PocketSwitch。开启轨道日间为近黑、夜间为白，关闭轨道使用中性灰，以滑块位置和对比度共同表示开关状态。豆瓣评分徽标使用金色星形和白色分数，保留封面原色，错误及资源可用性同时用文字说明。
- 手机底栏使用居中的烟晶渐变玻璃胶囊，以边缘阴影衬托，无描边。底部衬底向上渐隐，最大宽度 280dp。首页、历史、订阅、设置四个图标等宽，每项至少 48dp 热区，用图标对比度和直径 36dp 的轻底色标识选中项。读屏可读出页名和选中状态。底栏避让系统导航区，末项可滚到浮栏上方。宽屏侧栏保留图标及文字。首页分页使用弹簧移动下划线。
- 搜索框下直接显示可横滑的题材筛选，排序位于同一行右端。搜索中以输入框尾部的停止按钮取消请求。搜索与历史的横向卡片均保留 12dp 内边距，68×88dp 封面与标题顶部对齐，来源列表与封面共用左边线。展开时才出现内容分隔线。
- 首页推荐、分类卡片采用两列瀑布流，每张卡片进入较短的一列，列内与列间均留 12dp。头图、栏目标题及分页状态跨列。推荐头图及推荐、分类的双列作品卡共用外轮廓。以 3dp 阴影区分卡面，去掉外描边，封面与文字共用一个可点击卡面，片名距卡边 12dp。推荐头图按可用宽度采用 16:9，双列网格封面采用 2:3 竖版海报比例，评分只在封面徽标出现一次。图下按实际文字高度排列片名和可选元数据，行间 2dp，上下各 8dp；无元数据时收起整行。横向作品卡的封面与正文顶部对齐，加载占位与成图共用裁剪边界。检查长标题、展开来源和大字号。
- 首页首行左侧按顺序放推荐、分类、直播，右侧放全局搜索和当前频道的操作，去掉独立的应用名标题。点按频道或在内容区左右滑动可切换；纵向浏览时，上滑收起整组顶部控件（含分类和直播的附加筛选），下滑即可重新显示。检查斜向手势、列表滚动、输入框和系统侧边返回的交接。
- 首页点搜索图标立即打开独立搜索页。通过 SearchHeader 将返回键和输入框垂直居中，左右各留 20dp，控件间距 8dp。返回恢复进入搜索之前的频道和列表位置。历史页点击搜索后就地聚焦并筛选记录，输入框末尾保留清空操作，筛选图标与输入框同排，键盘搜索键收起键盘。
- 工具栏、搜索框动作及抽屉关闭键复用 GlassIconButton，热区 48×48dp，圆形底板直径 36dp，图标 20dp。海报叠层使用半透明黑底，播放器底部图标随控制栏显隐。历史列表首项与后续项共用同一封面、标题、进度和续播布局，每部作品仅显示最近观看的一集，保留续播断点。历史左滑露出删除图标，点击后确认。
- 文字按钮复用 GlassButton 或 GlassTextButton。按用途分组，同一行统一高度，组内间隔 8dp，大字号时允许换行。筛选使用 ContentFilterChip。选中项使用 onSurface 底色、surface 文字与勾选标记，未选项使用透明底。未知时长的等待用 PocketLoading 圆环；已有完成量时传入进度。播放时间轴和选集观看记录属于内容进度。选集在卡片背景表现进度，各状态的标题、次行及卡片边缘保持对齐。
- 手机操作、筛选和确认放在底部抽屉，全屏播放器使用侧抽屉。底抽屉以屏幕触点位移驱动承载模糊、渐变和内容的同一层。向下、反向拖动及回弹时，检查把手、玻璃上沿和内容同步位移，松手时结合位移与速度决定回弹或关闭，把手触控区至少 48dp。录入 JSON、规则等内容时，点击遮罩保留草稿；确认和取消之间留 8dp。点作品卡时在当前浏览页上方展开浮卡，保留两侧页边距、底层列表及滚动位置。封面从所点卡片的可见位置等比展开，右上关闭或系统返回沿原路径缩回该缩略图。收起末帧与原卡片的封面、圆角及评分角标逐像素衔接；用停在终点但尚未提交的侧滑验证。系统侧滑需跟手，取消后恢复展开态。点击简介中的“搜索片源”同时关闭浮卡，搜索返回直接显示原首页，返回预览也不能包含已关闭的简介。普通前进和分页直接显示目标内容。返回按钮和系统返回键触发收起动画；Android 14 起的系统侧滑按实际边缘和手势位移显示上一级，取消回弹，提交补完剩余距离。

## 横屏播放器

全屏点播长按画面显示目标时间、总时长与预览轨道，左右拖动可反向，松手才跳转一次；取消、离开窗口及切集清除预览，直播保留原播放位置。缓冲较慢时使用高对比深色底板和白字，操作区避开时间轴，大字号允许换行。

唤起时间轴时顶部同时显示设备时间和电量，隐藏时一起收起。播放、暂停、快退、快进和时间轴沿用 Media3 原生布局。顶部提供返回和播放标题。点播将当前集名放在片名前，长片名可以省略，直播只显示频道名。剧集增加上下集、选集和换源，设置沿用原生入口。左上箭头退出全屏。退出横屏时保持同一播放器和视频视图。控件可见时，顶部和底部用向画面中央渐隐的深色衬底承托白字与时间轴。中央保持透明，控件收起时同步撤去衬底。顶部和原生控制层共用对称的水平安全边距，左右均取两侧刘海避让值中的较大值，视频画面保持原宽度，保留滑块端点和按钮触控所需空间。

## 模拟器复核

按改动范围从正常入口操作，检查日间、夜间、长标题、大字号和键盘出现后的布局。导航看快速连点切换，抽屉看慢拖、反向拖和松手，播放器看显示、隐藏、拖动、切集与返回。用截图核对静态边缘，用真实触摸验证动作。UiLayoutDeviceTest 提供首页与主要页面夹具，PlaybackGestureDeviceTest 覆盖横屏控制。需要人工验收时可用 UiLayoutDeviceTest 的 manualDesignReview=true 保持夹具运行。

逐页审查时结合 mobile-design-system 的 Android 清单。沿首页推荐与分类、搜索、直播、历史、订阅、设置、详情、行内与全屏播放的实际入口检查按钮。包含抽屉、确认、空态、加载与失败重试。同一动作在日夜主题保持相同标签和触控热区。按当前应用窗口尺寸选择布局，在键盘打开、横屏及分屏时复核可达性。

订阅卡片左滑露出更新和删除图标，删除需确认，本地 JSON 更新打开文件选择器。直播无来源时仅保留管理订阅入口，有来源时来源与刷新同排，并与分页下划线留出间距。推荐和分类评分徽标共用金色星形。

详情页默认一屏，片名叠放在封面底部。封面下方的播放栏从左到右为圆形播放按钮、当前集数及片源清晰度、选集按钮。续播使用最近有效记录，有已知时长时以外圈显示该集观看比例，只有展开的简介可滚动。选集直接在一个抽屉内完成。推荐类型、题材和排序同层选择，应用后生效。历史与订阅左滑操作分别使用有边框的等高圆角按钮，按钮与卡片之间保留 8dp 空隙。

筛选项预留选中标记的位置，切换时相邻选项保持原位。播放器缓冲秒数只更新可见的状态文字。

## 烟晶黑（0.58 起）

烟晶色为默认外观，保留已设置的跟随系统及日间主题。续播栏和恢复提示使用共享渐变材质与细边框，正文、海报与列表保留平面。介绍和详情浮卡共用海报标题与右上关闭控件，独立详情页沿用左上返回。输入框内清除只清空内容；抽屉右上关闭只收起面板。返回最多约 170ms。手势预览只缓存返回路径中页面的最后画面，保持单个活动页面，遵循系统动画缩放。

全局搜索首批结果等待时，在列表按真实结果的封面与标题尺寸显示骨架，在骨架列表上方独立一行放置简短状态和一条细进度条。首个来源返回前显示流动进度，之后按已完成来源数更新。保留取消入口。任一片源返回作品后立即替换骨架，允许展开与选择，剩余片源继续更新进度，结束后按结果显示空态。分类页尾按加载、部分完成和下一页显示单一分页操作，状态与按钮纵向留间，避让回顶按钮。其他页面首次加载在内容区提示，刷新保留内容，追加在列表末尾显示，下载展示字节进度。封面槽位保持尺寸；有同源内存缩略图时详情沿用该图直到高清封面就绪，加载期间显示高斯模糊占位与斜向扫光，搜索骨架沿用扫光；成图、失败或无图时停止。订阅详情的返回与更多独占工具栏，标题在列表首项使用整行宽度，单行末尾省略，摘要和更新时间以次级字号显示。竖屏在视频底部控制栏右侧依次放置画中画与全屏，同时间轴一起显示和隐藏，横屏以左上返回退出。长剧集用每段 50 集的范围条与独立滚动网格；打开定位当前集，浏览范围不切集。

换源沿用图册同一组来源行，竖屏底抽屉、横屏约 42% 宽侧抽屉。固定标题和片名集数，进度开关显示实际断点，候选逐行显示来源或线路、集数与真实探测状态，当前来源单独标记。搜索来源按每条线路的起播集自动静音试播，同地址复用。视频以实际首帧、纯音频以播放进度推进为准。终态只有“可播放”和“不可播放”。搜索试播仅在结果列表可见且处于前台时运行。全屏浮卡覆盖列表或应用进入后台时暂停，返回可复用已验证结果。关闭搜索页后释放本次查询、结果和试播记录。关闭换源抽屉、进入画中画或离开播放器时，取消候选试播及排队请求；关闭抽屉后原视频继续播放。点击可播放来源直接打开已验证的线路和集数，返回恢复列表；点击海报可查看详情。换源按当前集数试播，实际播放失败时撤销该地址的通过标记。烟晶渐变面板叠在原播放器上，关闭和浏览不切源。以真实 Android 窗口截图比对图册，场景素材仅注入测试媒体。

## 播放页按钮验收

- 用真实频道和多集作品分别走一遍。直播页只出现一次频道名，显示频道分组和当前来源。直播没有集数、上下集和重试选集入口。网络失败时提供重新连接。
- 行内播放页的返回与更多共用顶栏基线和边距。进入全屏位于视频右下，避开 Media3 时间轴。剧集标题下将上一集、选集、下一集放在同一操作组；检查首集、末集和大字号。在支持画中画的设备上，行内播放器右下将画中画与全屏入口同排，两者间隔 8dp。为这组按钮在原生底栏预留空间，窄屏大字号放不下完整时间时，将两个快捷按钮一起移至视频底部独立一行，并与进度条的触摸范围分开；横屏保留画中画快捷入口。缓冲信息也在播放选项内。
- 从横屏打开全部选集侧栏，跨区间找到远端集数，关掉侧栏后核对当前集和断点。展示抽屉、切换横竖屏和浏览候选来源期间复用正在播放的会话。
- 返回动画覆盖页头和内容。以系统动画倍率 1× 检查前进首帧、双侧系统滑动的中间帧、反向取消、松手提交与按钮返回。检查露出上一级页面并连续录制提交后的几帧。另测进入后台、恢复再返回，检查封面、滚动位置及中断的手势。返回时已缓存的封面应首帧可见，交接期间保持目的页画面。预览缺失或尺寸不匹配时直接导航。系统关闭动效时检查页面直接可用。
- 审核材料包含同一版本的 Android 原始截图。至少区分首页和搜索、详情和推荐介绍、直播和剧集、横屏和行内播放。拖动玻璃时同时保留静止、下拉与反向三帧，检查空出区域能看到后方页面。


## 边缘与间距复核

- 一级页、搜索框、详情操作栏与正文共用 20dp 水平页边距。首页频道与同排图标中线对齐；小宽度和大字号下复核频道名称及两侧操作的可达性。分页下划线与筛选行间留 8dp。
- 来源、题材选择器和相邻图标使用 36dp 的可见底板及至少 48dp 的触控区。窄屏或大字号允许筛选换行，排序独占右侧。窄屏双倍字号时题材可横滑，排序可达，结果操作可滚动到浮栏上方。检查订阅、历史和设置的页头纵向起点。
- 全屏核对实际绘制的轨道首尾与顶栏两端按钮的可见外沿。计算时计入两侧较大的刘海安全区、滑块半径和圆底到热区之间的内缩。行内同时显示原生设置、时间、画中画和全屏时，逐对检查点击范围。短横屏加大字号时，选集区间与定位当前集共用一行，分季和来源可滚动，末段第 500 集仍可点选。

订阅首页按设置入口的样式展示订阅名称、来源数量及向右箭头。点击整行进入该订阅的独立详情页，来源开关放在详情页。手机与宽屏共用同一导航行为，顶部返回和系统返回都恢复原列表位置。同组行共用连续底色，组首和组尾使用外圆角，行间分隔线内缩 16dp。无数据提示复用 EmptyPanel，图标 24dp，上下留 24dp。设置与订阅入口复用整行点击的 PreferenceRow，行高至少 72dp，横向留白 16dp，标题与摘要间距 4dp，尾部箭头 20dp。设置列表末尾留出浮栏间距。更新弹窗按当前状态展示版本、发行说明、下载进度、错误和下一步操作，省去安装流程及文件处理说明。

底部导航选中使用实心图标，按压反馈与选中底板共用 36dp 圆形范围。抽屉的窗口模糊、底色和内容共用 20dp 圆角。

二级页面复用 BackHeading，搜索页复用同一个 PocketBack。36dp 圆底的可见起点与正文 20dp 边线对齐，48dp 热区向边缘延伸 6dp。普通页面用中性灰圆底，覆盖视频时用深色半透明底。浮卡与抽屉使用关闭键。
