# Pocket Live Android 界面

从当前页面及共享组件入手。以方案 A 修订图册的同名页面为视觉基准，再与 Android 同一入口、同一状态的截图并排比较。Theme.kt 管理主题色，GlassControls.kt 提供共享按钮、加载环和导航控件。

## 页面和操作

- 烟晶黑配中性灰阶正文。启用开关、进度和少数主操作共用主题 tertiary 的低饱和青色。豆瓣评分徽标使用金色星形和白色分数，保留封面原色，错误及资源可用性同时用文字说明。底部选中项通过图标对比度、标签字重和轻微阴影区分。阴影和实色圆角背景共用同一轮廓，移动时阴影贴合底板。
- 手机底栏为烟晶圆角浮栏，首页、历史、订阅、设置四项等宽，图标在上、标签在下。浮栏四周统一留 4dp，28dp 外圆角对应 24dp 选中背景圆角。浮栏与内容共用 20dp 左右边距，系统导航安全区留在外侧，列表末项可滚到浮栏上方。宽屏使用侧栏。选中底板和阴影同步使用阻尼弹簧移动，连续点击可中途转向。首页三个分页使用相同弹簧移动下划线。
- 首页推荐、分类卡片固定两列，头图和栏目标题跨列。推荐头图及推荐、分类的双列作品卡共用外轮廓。使用 1dp 细边、3dp 阴影，封面与文字共用一个可点击卡面，片名距卡边 12dp。网格封面宽高比 1.1，图下放片名和一行元数据。横向作品卡的封面与正文顶部对齐，加载占位与成图共用裁剪边界。检查长标题、展开来源和大字号。
- 首页推荐、分类和直播在浏览状态左侧显示页名，搜索入口靠右。进入搜索后用 SearchHeader 把返回箭头与搜索框排在同一行，中线对齐，左右留 20dp，箭头与搜索框间隔 8dp。搜索框占剩余宽度，× 清空输入，提交箭头居右。历史搜索沿用这一布局。工具栏并列图标复用 GlassIconButton，每个热区 48×48dp，可见圆底直径 36dp，图标 20dp。海报和视频上的图标沿用相同尺寸，使用半透明黑底。历史列表首项与后续项共用同一封面、标题、进度和续播布局，每部作品仅显示最近观看的一集，保留续播断点。历史左滑露出删除图标，点击后确认。
- 文字按钮复用 GlassButton 或 GlassTextButton。按用途分组，同一行统一高度，组内间隔 8dp，大字号时允许换行。筛选使用 ContentFilterChip。选中项使用 onSurface 底色、surface 文字与勾选标记，未选项使用透明底。未知时长的等待用 PocketLoading 圆环；已有完成量时传入进度。播放时间轴和选集观看记录属于内容进度。选集在卡片背景表现进度，各状态的标题、次行及卡片边缘保持对齐。
- 手机操作、筛选和确认放在底部抽屉，全屏播放器使用侧抽屉。底抽屉以屏幕触点位移驱动承载模糊、渐变和内容的同一层。向下、反向拖动及回弹时，检查把手、玻璃上沿和内容同步位移，松手时结合位移与速度决定回弹或关闭，把手触控区至少 48dp。录入 JSON、规则等内容时，点击遮罩保留草稿；确认和取消之间留 8dp。页面切换采用短距离横移与缩放，返回反向收起。

## 横屏播放器

唤起时间轴时顶部同时显示设备时间和电量，隐藏时一起收起。播放、暂停、快退、快进和时间轴沿用 Media3 原生布局。顶部提供返回和片名，剧集增加上下集、选集和换源，设置沿用原生入口。左上箭头退出全屏。退出横屏时保持同一播放器和视频视图。全屏控制层使用透明背景，唤起时间轴时维持视频原有亮度。顶部和原生控制层共用对称的水平安全边距，左右均取两侧刘海避让值中的较大值，视频画面保持原宽度，保留滑块端点和按钮触控所需空间。

## 模拟器复核

按改动范围从正常入口操作，检查日间、夜间、长标题、大字号和键盘出现后的布局。导航看快速连点切换，抽屉看慢拖、反向拖和松手，播放器看显示、隐藏、拖动、切集与返回。用截图核对静态边缘，用真实触摸验证动作。UiLayoutDeviceTest 提供首页与主要页面夹具，PlaybackGestureDeviceTest 覆盖横屏控制。需要人工验收时可用 UiLayoutDeviceTest 的 manualDesignReview=true 保持夹具运行。

逐页审查时结合 mobile-design-system 的 Android 清单。沿首页推荐与分类、搜索、直播、历史、订阅、设置、详情、行内与全屏播放的实际入口检查按钮。包含抽屉、确认、空态、加载与失败重试。同一动作在日夜主题保持相同标签和触控热区。按当前应用窗口尺寸选择布局，在键盘打开、横屏及分屏时复核可达性。

订阅卡片左滑露出更新和删除图标，删除需确认，本地 JSON 更新打开文件选择器。直播无来源时仅保留管理订阅入口，有来源时来源与刷新同排，并与分页下划线留出间距。推荐和分类评分徽标共用金色星形。

详情页默认一屏，片名叠放在封面底部。封面下方的播放栏从左到右为圆形播放按钮、当前集数及片源清晰度、选集按钮。续播使用最近有效记录，有已知时长时以外圈显示该集观看比例，只有展开的简介可滚动。选集直接在一个抽屉内完成。推荐类型、题材和排序同层选择，应用后生效。历史与订阅左滑操作分别使用有边框的等高圆角按钮，按钮与卡片之间保留 8dp 空隙。

筛选项预留选中标记的位置，切换时相邻选项保持原位。播放器缓冲秒数只更新可见的状态文字。

## 烟晶黑（0.58 起）

烟晶色为默认外观，保留已设置的跟随系统及日间主题。浮动导航、续播栏和恢复提示使用共享渐变材质与细边框，正文、海报与列表保留平面。影片介绍和详情共用海报标题与左上返回控件。输入框内清除只清空内容；抽屉右上关闭只收起面板。卡片进入约 210ms，返回约 170ms，保持单个活动页面，遵循系统动画缩放。

等待时首次加载在内容区提示，刷新保留内容，追加在列表末尾显示，下载展示字节进度。封面槽位保持尺寸；有同源内存缩略图时详情优先展示低分辨率模糊预览，否则用静态玻璃占位。竖屏在视频右下进入全屏，横屏以左上返回退出。长剧集用每段 50 集的范围条与独立滚动网格；打开定位当前集，浏览范围不切集。

换源沿用图册同一组来源行，竖屏底抽屉、横屏约 42% 宽侧抽屉。固定标题和片名集数，进度开关显示实际断点，候选逐行显示来源或线路、集数与真实探测状态，当前来源单独标记。烟晶渐变面板叠在原播放器上，关闭和浏览不切源。以真实 Android 窗口截图比对图册，场景素材仅注入测试媒体。

## 播放页按钮验收

- 用真实频道和多集作品分别走一遍。直播页只出现一次频道名，显示频道分组和当前来源。直播没有集数、上下集和重试选集入口。网络失败时提供重新连接。
- 行内播放页的返回与更多共用顶栏基线和边距。进入全屏位于视频右下，避开 Media3 时间轴。剧集标题下将上一集、选集、下一集放在同一操作组；检查首集、末集和大字号。在支持画中画的设备上，行内播放器右下将画中画与全屏入口同排，两者间隔 8dp。为这组按钮在原生底栏预留空间，窄屏大字号放不下完整时间时，将两个快捷按钮一起移至视频底部独立一行，并与进度条的触摸范围分开；横屏保留画中画快捷入口。缓冲信息也在播放选项内。
- 从横屏打开全部选集侧栏，跨区间找到远端集数，关掉侧栏后核对当前集和断点。展示抽屉、切换横竖屏和浏览候选来源期间复用正在播放的会话。
- 卡片进退覆盖页头和内容。以系统动画倍率 1× 录制一次进入与返回，检查中间帧的两张页面、遮盖顺序和返回方向。系统关闭动效时检查页面直接可用。
- 审核材料包含同一版本的 Android 原始截图。至少区分首页和搜索、详情和推荐介绍、直播和剧集、横屏和行内播放。拖动玻璃时同时保留静止、下拉与反向三帧，检查空出区域能看到后方页面。


## 边缘与间距复核

- 一级页、搜索框、详情操作栏与正文共用 20dp 水平页边距。推荐搜索和筛选、分类排序、直播刷新均在同一列；对照真实截图检查同列按钮的圆心。分页下划线与筛选行间留 8dp。
- 来源、题材选择器和相邻图标使用 36dp 的可见底板及至少 48dp 的触控区。窄屏或大字号允许筛选换行，排序独占右侧。窄屏双倍字号时，搜索结果统计换到标题下一行，结果操作需可滚动到悬浮导航上方。检查订阅、历史和设置的页头纵向起点。
- 全屏核对实际绘制的轨道首尾与顶栏两端按钮的可见外沿。计算时计入两侧较大的刘海安全区、滑块半径和圆底到热区之间的内缩。行内同时显示原生设置、时间、画中画和全屏时，逐对检查点击范围。短横屏加大字号时，选集区间与定位当前集共用一行，分季和来源可滚动，末段第 500 集仍可点选。
