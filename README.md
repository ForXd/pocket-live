# Pocket Live · 口袋片源

一个 Android 订阅播放器。**不内置、不分发任何订阅源、直播频道列表或视频播放地址；播放来源必须由用户自行添加。**

豆瓣推荐仅展示片名、评分和海报。点击推荐后，应用只搜索用户自己启用的来源，不从豆瓣获取播放地址。

## 安装与使用

从本仓库 Releases 下载签名 APK，支持 Android 8.0 及以上。

1. 在“订阅”页添加自己的订阅链接，或选择 JSON 文件 / 粘贴 JSON 内容。点击卡片展开或收起来源，按需启用。订阅右侧菜单用于在线更新、本地文件替换或删除，来源右侧菜单用于配置精确广告路径。
2. 在“搜索”或“发现 → 订阅分类”中查找内容，打开详情后选择线路和集数。
3. 播放失败或卡顿时点击“快速换源”。优先显示当前来源的同集备用线路，再查询已启用来源中同名、同集的结果。
4. 可选择保留当前进度；不同剪辑版本的时间可能不完全对应。不按列表下标猜测集数，不会自动跳到别的剧集。
5. 网络不稳定时可开启“流畅优先”。多码率视频优先不超过 720p / 2 Mbps 的轨道；单码率视频无法凭空生成低清晰度，可尝试换源。

## 历史与应用更新

同名点播剧目会跨来源合并为一张历史卡片，继续观看默认使用最近一次来源和断点。展开后显示各来源的分集记录，删除整部剧会删除该组所有来源的历史。只统一空白、大小写和全半角，不去掉季数、年份等标题信息；直播仍按来源区分。标题相同但实际内容不同的资源可能归入同一组，可通过展开后的来源名称区分。

正式版启动或回到前台时检查 `ForXd/pocket-live` 最新正式 GitHub Release，每次运行至多每 24 小时自动检查一次；右上角“更新 / 有新版”可查看结果和手动重试。点击“下载并安装”直接在应用内下载，显示进度，支持取消和重试，不打开浏览器。下载后核验 GitHub SHA-256、包名、版本与现有签名，再通过私有 FileProvider 交给 Android 确认安装。首次需要允许本应用安装未知应用；不会静默安装。请保留原应用，勿先卸载。

更新使用流式下载，单个安装包最多 12 MB，下载前检查应用文件 50 MB 预算和可用磁盘。关闭更新弹窗后下载继续；进程被系统结束后，未完成的下载需要重试，已完成的安装包可恢复并在升级后自动清理。未实现断点续传或后台保活。

右上角“外观设置”提供跟随系统、日间和夜间三种模式，即时生效并保存。横屏全屏播放器保持深色控制界面。新版图标采用口袋折面与播放三角的组合，界面统一使用青绿强调色、分层卡片和 Material 3 排版。参见 [v0.8.0 界面与验证记录](docs/ui-v0.8.0.md)。

发现页海报请求随页面前台生命周期执行，进入后台时取消，回到前台重试失败图片；刷新推荐也可重试海报。推荐刷新失败保留同一分类的已有内容，并显示重试入口；空列表、失败或超过五分钟的推荐在重新进入前台时检查刷新。推荐请求总时限 22 秒，包含排队时间。

## 播放与资源策略

- v0.15.0 提前补充点播缓冲：时间目标为 50–60 秒，首次起播阈值仍为 1 秒、再次缓冲阈值 4 秒，无需等到 50 秒才播放。媒体缓冲分配目标仍为 32 MiB，达到字节目标可提前停止预取，不代表整个进程的内存硬上限。提前退出可能多预取部分数据。参见 [优化与验证记录](docs/buffering-v0.15.0.md)。
- 缓冲较慢时提供重新连接和换源入口。临时加载错误最多重试两次；404 / 403 等明确失败不反复请求同一地址。
- 每次播放拥有自己的媒体请求集合。退出、换源、后台停止时先取消旧请求，再释放播放器；复用应用连接池，不为每次播放创建线程池。
- 备用来源查询最多检查 12 个已启用来源、同时查询 3 个，结果最多 40 条。关闭面板或切换播放会取消查询，旧结果不能覆盖新会话。
- 自写磁盘文件预算为 50 MB；视频不落盘。缓存可以在订阅页清理，订阅和历史保留。APK 和系统编译缓存不计入此预算。
- 可选的 HLS 广告过滤默认关闭，可能误判；复杂、加密、多码率或直播流保持原样。

片源服务可用性和持续带宽无法由播放器保证。豆瓣公开元数据接口也可能限流或变更。

## 订阅格式

`examples/subscription.json` 是空模板，不含任何地址。链接、文件和粘贴入口共用 `SubscriptionParser`，兼容 LibreTV `sources/liveSources`、源数组、source-catalog `baseUrl` 目录与 TVBOX `sites/lives` 直连配置；不会执行来源里的脚本、网页解析或 DRM 解锁。

v0.16.0 支持通过系统文件选择器导入 UTF-8 JSON（最多 2 MiB，兼容 BOM、注释与尾逗号），或直接粘贴 JSON。文件来源标为“本地 JSON”，可从订阅菜单“重新选择 JSON 文件”替换；无效配置不会覆盖原订阅。导入后删除原文件不影响已保存来源；文件不会自动同步。相同内容重复添加会提示已存在。详细验证见 [JSON 导入记录](docs/json-import-v0.16.0.md)。

订阅保存在应用私有目录，系统备份已禁用。应用不上传订阅及观看历史至本项目服务器；导入、搜索与播放会按用户操作直接访问相应来源。推荐会访问豆瓣元数据和图片域名；更新检测会访问 GitHub 官方 Release API，不携带订阅或观看记录。

## 本地构建

需要 JDK 21、Android SDK Platform 37，以及 Android SDK Build Tools。设置 `JAVA_HOME` 和 `ANDROID_HOME` 后执行：

```sh
# 安装测试需要独立的高版本测试 APK；仅打包到 androidTest，不进入正式版。
# 先构建 debug 以生成默认 debug.keystore（首次构建时需要）。
./gradlew assembleDebug
./scripts/build-update-fixture.sh
./gradlew testDebugUnitTest assembleDebugAndroidTest assembleRelease
```

Release 默认不配置签名，私钥由开发者在项目外保存，通过 `apksigner` 签署产物。不要提交私钥、口令或用户订阅。

重复运行 `ApkUpdaterDeviceTest` 前，请在测试进程外执行 `adb shell appops set org.streampocket.devtest REQUEST_INSTALL_PACKAGES default`；Android 撤销安装权限会终止该应用进程。可加 instrumentation 参数 `-e actualInstaller true` 验证真实系统安装确认页（测试会取消，不安装夹具）。

设备测试使用本地 MockWebServer 与测试媒体；真实豆瓣联网测试单独位于 `DiscoveryDeviceTest.liveDoubanAndCoverDecode`。测试 APK 的包名是 `org.streampocket.devtest`，正式包名为 `org.streampocket`。
