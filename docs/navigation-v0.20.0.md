# v0.20.0 · 首页与设置重组

## 操作结构

- 首页合并发现与搜索：默认展示继续观看、推荐及订阅分类，搜索栏位于 Scaffold 顶部，内容滚动时位置固定。键盘搜索键与按钮使用同一个提交动作。
- 提交后同页展示搜索状态、结果或空状态，标题明确显示提交的关键词。输入框内修改关键词不会把旧结果冒充成新结果。
- 清空按钮、返回推荐按钮或搜索结果页的系统返回键均取消当前搜索并回到推荐；详情返回则先回到结果。结果与推荐使用分开的可保存状态，返回推荐保留筛选/排序和滚动位置。
- 主导航为首页、订阅、历史、设置。为满足固定右下角入口，手机和宽屏均使用底部四项导航，设置始终最右，宽屏正文继续限制最大宽度。
- 设置页集中外观、应用更新、播放与网络、缓存、来源广告规则、关于。更新卡片显示检查/下载/校验/待安装状态；沿用已有签名校验、下载取消及系统安装确认。首页、详情顶部不再放设置或更新按钮。
- 订阅页专注来源的添加、导入、启停、替换与删除。订阅自身的内容更新保留在订阅菜单，区别于应用版本更新。播放器保留当前播放的选集、换源、流畅优先等快捷控制；广告过滤说明指向设置页。

## 参考

参考 Apple TV 的内容推荐与查找组织、Spotify 的偏好归类及 Android 官方搜索/导航原则。具体合并方式与右下角设置位置来自本次用户要求，不宣称复制这些产品的界面。来源与取舍见 [官方调研](navigation-research-v0.20.0.md)。
