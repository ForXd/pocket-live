# 首页浏览与多选搜索

题材多选采用“符合任一项”的并集规则，不选表示不限题材。订阅来源默认全选范围：空选择集合代表全部已启用来源，只有主动选定来源时才缩小查询范围。

- 筛选面板支持连续勾选、再次点选取消和重置；点“应用”才提交，取消、返回或点面板外部不提交草稿。首页已选条件可以逐项移除，最后一项移除后恢复不限。
- 来源原始分类 ID 只在单来源范围内使用，避免跨来源复用错误 ID。多题材按真实分类及影片标签取并集，按来源和影片 ID 去重。未完成分类页轮流查询，每批每来源最多四页。
- 首页推荐固定两列，缩短海报和文字区间距，保留两行片名。上滑收起搜索栏并归还布局空间，下滑恢复；键盘打开时搜索栏保持可见。六张完整卡片以正常字号的 1080 × 2400、420 dpi 设备验证，不把裁切卡片计入数量。
- 全来源片库查询最多四路并发，每来源超时 25 秒、整体 45 秒，结果上限 1000 条。单个来源失败保留其他来源结果，后续可继续尝试。

## 来源健康缓存

搜索与片库分别记录成功/失败。调度顺序为近期成功、未知、近期失败；失败来源降序而不永久排除，恢复成功后立即重新优先。空结果的成功响应仍算成功，用户取消不算失败。

缓存只存来源哈希、操作类型、结果和时间，不存 URL、凭据或界面对象。成功有效期七天，失败三十分钟，最多 600 条、文件最多 128 KiB；删除或停用来源时清理内存条目。磁盘读写在 IO 调度器进行，写入合并为一个受 ViewModel 生命周期约束的任务，临时文件原子替换。缓存不可用不影响正常查询。

## 验证与交付

单元测试覆盖多题材并集、分页公平性、缓存排序/隔离/恢复/过期、容量上限、合并写入及取消清理。设备测试覆盖多来源默认范围、连续多选/清空/取消、部分失败恢复、第三页命中、搜索栏滚动和键盘边界。六卡验收使用未裁切的布局边界。
