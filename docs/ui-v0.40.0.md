# v0.40.0 统一玻璃材质与推荐介绍

保留已确认的「幕间」方向：暖黑 / 米白、简洁层级、同一套字体和 8 / 12 / 16 / 20dp 圆角。此次从共享组件修正样式，而不是另换主题。

## 统一界面

- 更多播放选项、快速换源、全屏选集都使用同一原生毛玻璃窗口，横屏从右侧展开半屏。中心确认框、外观、更新、管理菜单和底部筛选也使用同一材质。模糊半径 24dp、上限 80px；有模糊时底色透明度约 78%，系统不支持模糊时使用 96% 底色保证可读。
- 面板圆角统一 20dp、细边框、相同标题层级。控件用半透明着色和细边框，取代实心主按钮；海报上的播放按钮固定使用浅色图标与深色透明底，保证日夜模式都可辨。
- Media3 原生设置入口转入相同的播放选项面板，保留倍速、音轨及可用字幕选择；选中音轨与自动选择互斥显示。
- 底部导航和大屏侧栏有明确选中底色与加粗标签。可用媒体统一显示柔和绿点加“媒体可用”文字，搜索、分类搜索和换源复用同一组件。
- 底部面板处理系统导航栏和键盘安全区，筛选完成、导入说明不会被系统按钮遮挡。长菜单可滚动，播放选项在小屏横屏及大字号下保持独立滚动。

## 推荐介绍流程

首页海报和主推荐按钮先打开介绍页，展示海报、片名、评分、基本信息及剧情简介；只在用户点击“搜索片源”后发起搜索。返回保留首页浏览状态。介绍页沿用普通页面标题、正文和半透明主按钮，大字号时海报与标题改为上下排列。

推荐内容来自豆瓣公开页面及基本信息接口。真实访问中基本信息接口可用，但剧情页面可能返回验证页；不把验证页、短评或虚构内容当作剧情简介。此时明确显示暂未获取到简介，提供重试和继续搜索入口。测试夹具验证了简介成功、返回、手动搜索路径，不能把夹具成功当作第三方服务始终可用。

## 搜索与换源探测

搜索之前串行检查、只检查第一条线路，并缓存失败结果；当第一条线路失效、解析页不可播放或来源较慢时，会漏掉可用备用线路。现在普通搜索和分类关键词搜索共享探测流程：最多三路并发，每部影片尝试各线路首集，复用换源相同的媒体验证规则。换源仍检测用户当前集。

两边确认两个可用结果就停止并取消剩余探测；搜索本身继续收集其他结果。可用项优先，未知、加密和失败不计入成功。只短期缓存成功结果，失败不会阻止下次搜索重试。探测读取不超过 64 KiB，识别有效媒体头后提前结束，不创建播放器。单媒体 5 秒、单影片 18 秒；搜索会等待流式搜索结果，整体探测最多 60 秒、40 个候选。离开、后台、换查询、取消都释放请求，并隔离旧会话的迟到结果。

## 验证与边界

实际界面截图及日志位于本地 artifacts/v0.40.0/。独立视觉评审发现的底部安全区、浅色海报播放按钮对比问题已修复，并以普通和两倍字号截图复核通过。手机日夜、两倍字号及宽屏介绍/主要页面已通过可达性回归。播放设置的实际倍速切换、全屏换源、选集和窗口反复关闭通过设备测试。

搜索专项回归覆盖首线路失败后的备用线路、三路同时发起、达到两个结果立即取消、分类搜索、旧查询取消；资源压力测试中播放器创建/释放一致，残留弱引用和活动媒体请求为零。性能与资源结论仅限已测试的模拟器路径，不承诺所有设备或外部片源都不存在故障。

独立 UX 走查由隔离会话 `glass_ux_review` 执行，实际从首页进入简介、手动搜索、打开详情、续播及换源失败恢复。主要操作可达。其夹具的媒体地址故意不返回视频，因此该次走查的播放失败属于测试数据；成功解码和切换由 PlayerLayoutDeviceTest 单独覆盖。低优先级剩余改善：换源无结果时提示添加来源，当前需返回订阅页操作，没有面板内的直接添加入口。操作证据在 `artifacts/v0.40.0/ux/`。
