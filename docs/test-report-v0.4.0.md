## 发布内容边界

- 应用初始订阅与示例订阅均为空，没有内置播放源、频道列表或视频地址。
- 保留豆瓣推荐的片名、评分、海报；播放仅搜索用户启用的来源。
- 测试服务器使用合成地址，测试视频是生成的测试图案；它们仅位于测试目录，不进入正式 APK。
- 正式 APK 的 assets 仅包含许可证和编译配置数据。签名私钥、口令、用户订阅、历史、堆转储及本地日志均未提交。
- APK 通过 v2 / v3 签名校验，提供 SHA-256 校验文件。

## 性能策略与限制

媒体缓冲目标 20–60 秒、分配目标 32 MiB；首次播放阈值 1 秒，再缓冲阈值 4 秒。“流畅优先”偏好多码率视频的 720p / 2 Mbps 以内轨道，不能为单码率视频转码。无法保证源服务器带宽或可用性。快速换源需要用户已添加的来源中存在同名同集候选；匹配不到时不会按数组下标猜测剧集。
