# v0.26.0 题材分类搜索

纠正 v0.25.0 对“分类”的理解：用户需要爱情、悬疑等题材，而不是电影、剧集等媒体形式。

- 搜索结果的分类条改为全部题材、爱情、悬疑、喜剧、动作、科幻、惊悚、恐怖、犯罪、剧情、冒险、奇幻、战争、历史、家庭、未标注题材。题材从 `vod_class` 和源站 `type_name` 读取，同一影片可以同时属于爱情和悬疑；不按片名、简介或跨站数字 ID 猜测。
- 首页“分类搜索”增加相同的题材入口。选择题材时，若当前源返回唯一对应分类（例如爱情片），将其真实 ID 作为 `t` 查询，可不输入关键词，也可与关键词 `wd` 联用。
- 源站没有对应分类，或同一题材对应多个分类时，不擅自选择其中一个；查询来源全部分类后按已加载影片标签筛选。页面明确显示该范围，并保留加载下一页操作。缺失题材标签归入“未标注题材”，不会假装已经搜索整站。
- 保留来源原始分类条，用户仍可直接选择源站的具体分类；选择原始分类时重置本地题材筛选，避免隐含条件。切换来源也重置题材与关键词。
- 卡片显示源站题材，便于核对筛选结果。保持 v0.25.0 的日夜主题、固定搜索栏和底部导航。

验证使用受控片库，覆盖同一剧集的多个题材、仅凭片名不误分、未知题材、原始分类 ID、无关键词浏览和题材加关键词查询。截图与构建记录位于忽略目录 `artifacts/v0.26.0`。
