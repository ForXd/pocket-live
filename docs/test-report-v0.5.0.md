# v0.5.0 本地验证记录

日期：2026-10-26。macOS / JDK 21 / SDK 37 / API 37 ARM64 本地模拟器。版本 0.5.0，versionCode 11，沿用原签名。

## 发现页故障反馈回路

执行 `am instrument -w -e class org.streampocket.DiscoveryRecoveryTest org.streampocket.devtest.test/androidx.test.runner.AndroidJUnitRunner`。

修复前：本地推荐正常返回，海报端点临时返回 503；恢复端点并让应用从后台回到前台，等待 7 秒仍无封面，测试失败。旧海报组件只按 URL 启动一次加载，失败后没有前台恢复触发。

修复后：同一测试通过。并验证刷新推荐返回 503 时保留现有卡片，恢复服务后再次前台进入可重新加载；同一条目的封面 URL 更新后请求新图。所有场景无需终止进程或重建 ViewModel。

这证明修复了可复现的失败状态滞留问题，不代表已确定用户设备当时的网络故障原因。豆瓣接口限流或不可达时仍会显示错误，可使用重试或订阅分类。
