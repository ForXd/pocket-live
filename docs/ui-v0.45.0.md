# v0.45.0 来源合并与多季选择

方向：影片为主，来源为辅。借鉴用户提供的搜索 / 历史 / 播放参考图，在已有浅灰底白卡与深色玻璃控件体系上整理层级；保留无边框按钮、整项导航高亮和静态波浪分集进度，不另加装饰背景。

搜索：一部作品一张主卡，海报、标题和查看详情为主动作；明确标注的季数以横向选项切换，该季的来源压缩为列表，可分别进入。来源只在实际媒体探测成功时显示绿点。来源较多时默认露出两项，其余可展开。

详情 / 播放：共用季数与来源选择。进入详情后在已启用来源中补查同系列，最多 12 个源、并发 3、总超时 20 秒、每源 8 秒，结果最多 200 项。刷新失败保留已知项并提供重试；关闭详情取消请求。不会修改主搜索关键词与结果。全屏选季放在原半屏侧栏中；浏览不改变正在播放的视频，选定具体剧集后才切换。单个详情请求有 15 秒超时，切换或关闭面板会取消旧请求。

历史：同系列来源和季归于一张卡。一步展开分集，切季后标题摘要、继续播放与分集列表同步；不同季的同一集号分别保存断点。历史仍以原始 100 条播放记录为唯一持久数据，不迁移或改写断点。

识别边界：归一化空白、全半角及大小写，识别「第 N 季」「Season N」「SNN」和常见中文季数；标题其余文字、版本及同季年份保留。电影年份不同不合并；缺季数、别名、罗马数字和语义相近标题不猜测。提供方分类不一致时保守分开。没有明确季数或当前来源未提供某季时，不能保证自动发现，可继续使用重新搜索。

动效：延续列表短淡入、筛选反馈与导航 160ms 色彩过渡；不为进度增加持续动画。验证关注真实播放会话隔离、分季断点、来源探测、失败重试、手机 / 夜间 / 两倍字号 / 大屏选集可读性。

独立评审：`/root/v045_visual_review` 审阅日夜 10 张实际截图，`/root/v045_ux_review` 从搜索自主走到跨季实际播放。已按反馈区分“正在播放 / 正在浏览”，给来源行添加进入箭头，缩短来源按钮并移除挤压文字的弹性间隔。历史标题另起一行，选季后摘要同步，宽屏详情返回控件提前固定避免遮挡标题。评审与截图位于 artifacts/v0.45.0/。

回归：139 项单元测试；9 项功能设备测试覆盖来源合并、未搜索季的补查与重试、历史断点、搜索筛选、媒体并发探测、500 集选集、换源断点、存储兼容及边缘手势。手机日夜、2 倍字号和 1280×800dp 宽屏流程通过。源码与模拟器测试使用夹具海报/短彩条视频，不代表任意外部来源的可用性。

资源回归初次发现补查季信息的慢请求在开始播放后仍保持到超时，已改为开始播放、快速换源、停止或后台时取消未完成补查，保留已知结果，进入选季后按需补查。测试环境也修复了换源用例沿用前例订阅造成的来源域名冲突，以及收起的搜索栏需要先下滑展开再点击的物理触摸前置条件。

补查入口按用户动作触发，不在播放返回详情的重组中重新启动；历史续播同样暂停未完成补查。快速换源对旧记录缺失的分类/年份允许匹配候选，但已知的冲突年份、版本或季数不会互相匹配，搜索分组仍使用严格身份。

最终资源压力回归通过：20 轮切换 / 后台恢复创建与释放播放器 52/52，活动媒体请求、换源探测请求和残留播放器弱引用均为 0；四次 Java 堆采样约 8.2 / 8.2 / 7.7 / 9.0 MB，最大释放耗时 56ms。七项预取测试通过，受控高延迟 HLS 二次缓冲 1 → 0，三切片约 2572ms。以上结论仅限本次受控模拟器路径，不承诺所有物理设备及外部片源表现。
