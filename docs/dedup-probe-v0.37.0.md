# 0.37.0 域名去重与探测清晰度

搜索（含同名换源搜索）先按近期健康结果排序，再按 API URL 的规范化精确 host 去重，保留第一个启用来源。跨订阅、同域不同路径/端口不重复搜索；订阅配置不删除。域名大小写、IDN、末尾点归一，不把不同子域或公共后缀下的不同站点合并。

对于不同域名的重定向别名，仅在一次真实 API 请求成功解析有效 CMS list 数组后记住终点，后续搜索按已观察终点合并；首次未知别名仍可能分别请求。不增加全来源预检请求，不把登录 HTML/失败响应当成同站证据。映射仅内存保存，最多 300 项、1 小时过期，关闭网络对象时清空。

媒体探测从已验证可达的 HLS 变体读取 `RESOLUTION`，显示“播放清单 · 宽×高”，与源站自报质量分开。没有声明、只返回媒体列表/直接容器或无法验证时显示“清晰度未确认”，不按文件名或码率猜分辨率，也不等同于实际解码测量。保留 2 个可用即停止、总耗时/候选数/读取字节限制；缓存新增分辨率字符串，不缓存媒体字节或播放器。

## 实际查询与资源边界

使用仓库外私有用户订阅配置查询“谷雨”，地址未写入仓库、APK或公开日志。初次 Android 直连遇本机既有代理的保留地址 DNS，被安全策略拒绝；使用本机已有代理后查询完成，未更改应用网络安全检查，测试结束恢复设备代理设置。

初次成功实测：11 个独立域名查询完成，返回 66 条结果；30 秒探测预算内 1 条媒体可达、7 条探测失败、未读到清单分辨率。其余未确认，不宣称找到了两条或真实清晰度。可控设备夹具则验证两个可用即停止、返回1920×1080、跨订阅同域只请求一次、保留其他搜索结果、缓存复用和切换查询取消。

连续 10 次搜索/取消，检查网络请求清空、未创建播放器、采样任务及媒体请求归零。该路径的资源释放与有界缓存验证不等于所有设备/所有输入的完整堆泄漏证明。

## 0.37.0 下载路由故障与 0.37.1 补丁

0.37.0 的普通 GitHub 浏览下载路由持续返回 HTTP 504，旧版应用内下载同样失败。官方 asset API 下载及带标准 download 参数的公开下载文件均与签名构建逐字节一致；原包未损坏，重新上传相同字节、重新发布元数据均未恢复普通路由。因此不将 0.37.0 记为升级验收成功，也不修改旧版校验规则绕过。

改用 0.37.1 / versionCode 45 的新发布路由：仅递增应用版本，功能与 a705455 相同，从新提交重新构建和签名，重新验证旧版真实升级。此补丁不替换同版本包内容。
