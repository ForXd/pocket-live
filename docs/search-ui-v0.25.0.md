# v0.25.0 搜索与界面

## 设计与范围

使用 [oil-oil/oil-ui](https://github.com/oil-oil/oil-ui) 0.32.0 的存量界面润色流程。本机安装位置为 `~/.codex/skills/oil-ui`，不把外部 skill 复制进应用。沿用 [首页设计依据](navigation-research-v0.20.0.md)：固定搜索栏、四项底部导航、右下角设置、青绿强调色、日间浅背景和夜间深背景。

搜索结果采用片名、分类/剧集信息、来源、清晰度四层信息。去掉搜索卡片固定的两行空槽，收紧海报与文字间距，保留来源以区分同片的不同播放入口。推荐海报继续贴边，不增加白框。首页二级入口缩短为“推荐 / 分类搜索”。分类搜索支持键盘搜索键，提交后收起键盘。

沿用 Material 选中状态过渡、搜索进度动画、结果淡入和卡片按压反馈。搜索过程用户开始操作后停止自动重排，避免目标移动；主动选择排序时重新排列。

## 搜索规则

- 默认相关度：完整片名 > 片名开头 > 片名包含 > 多词全部命中或来源声明的别名 > 其他源站结果。同等级再按清晰度排序；可手动选择“高清优先”。
- 匹配统一全半角、大小写、空白和标点；不把季数、数字或年份删除，也不根据清晰度猜测内容。
- 默认展示片名/别名匹配结果。“展开其他源站结果”保留源站可能基于演员、简介等返回的内容，避免直接丢弃这些结果。
- 结果内按电影、剧集、动漫、综艺、直播、其他筛选。分类来自来源的 `type_name`；`type_id` 仅在同一来源内有意义，不能跨来源硬编码。缺少或无法识别的分类归入“其他”。分类筛选只作用于本次已加载的结果。
- “分类搜索”入口按来源返回的原始分类查询，将 `t` 和 `wd` 一起发送给来源，支持继续翻页。源站是否支持这些参数及其分类准确性由源站决定。
- 保留每源 100 条、总计 1000 条、4 路并发和超时上限。用户尚未操作列表时，迟到的高相关结果可以替换达到上限的低相关结果；开始操作后保留现有顺序。

这不是模糊语义搜索，也不进行跨来源相同影片合并。无法从缺失的源数据可靠推断分类、简繁转换或拼音；不声称对所有第三方来源都提升了查全率。

- 单元测试 107 项通过，包括相关性优先于画质、全半角/标点/大小写、别名、多词匹配、分类元数据、迟到精确结果与总数上限。
- Release lint 无错误；顺带改用 LocalActivity 获取窗口，并将封面刷新流的初始值读取放入 remember，解决本次检查发现的两个 Compose lint 错误。
- 独立视觉评审 `/root/visual_review_025` 对比了新旧截图，保留主题与导航，按反馈压缩顶部辅助行、将分类提交收进输入框、去除重复清晰度并弱化未知状态。没有视觉打分。

- 独立 UX 走查 `/root/ux_review_025` 实际从分类结果进入详情、播放器及换源反馈；修正固定“正在播放”标题，改成“当前剧集”，避免播放失败时状态矛盾。夹具不提供视频字节，未据此评价正常视频播放。证据在 `artifacts/v0.25.0/ux-review`。
- 最终设备回归 7 项通过：搜索相关性与分类、首页/详情/设置布局、清晰度标识、推荐与分类请求、发现排序、更新下载与失败/取消校验。测试环境 Android API 37 模拟器；没有以模拟器结果替代特定厂商安装器兼容性结论。
- 最终搜索流程在日间/夜间 1080×2400、840×1800 两倍字体、1920×1200 宽屏分别通过。主 Agent 查看实际截图并复核筛选、卡片与固定导航布局。
