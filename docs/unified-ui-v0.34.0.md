# 0.34.0 统一内容界面

以同一种内容语言服务浏览、查找和续播，保留青绿日夜主题及各功能必要差异。

- 推荐移除继续观看区块及其分组计算，仅独立“最近观看”标签展示历史卡片。
- 首页与历史共用 ContentSearchField：56dp 最小高度、14dp 圆角、填充底色、搜索图标、单行输入和搜索键盘语义。历史增加关键词清空入口，仍是本地即时筛选；首页保留提交按钮及网络搜索，订阅 URL 等普通表单不受影响。
- 推荐/分类复用已有 ContentCard，与搜索和历史一致；最近卡使用同款表面、圆角和主按钮，海报贴合外缘，无独立底边圆角。
- 历史选项使用共享 ContentFilterChip，来源采用同款下拉按钮。各处排序统一图标入口与无障碍描述。搜索结果数、来源数合并，移除重复统计标题。
- 历史续播用浅色主按钮，分集/删除保持文本次操作；大字号操作允许换行，筛选组保留 8dp 间距。详情底部使用共享细分隔线。

保留两列海报、搜索位置恢复、最近卡片堆叠及相邻预加载、弹窗仅把手拖动关闭、紧凑导航。没有新增缓存、网络请求或后台任务。

独立视觉评审（存量、不打分）提出筛选间距、统计层级、主次操作与排序入口问题，均已修正。近期卡固定续播按钮和大字号可滚动信息区保留；测试简介文案不是产品固定文案，不作为实际影片内容修改。此次为视觉统一和删除重复入口，不改变主要业务流程，按轻量 UX 协议不额外派独立操作走查，真实设备回归覆盖。
