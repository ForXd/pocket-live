# v0.43.0 日间主题与全屏纵向手势

日间使用纯白页面、黑色主文字和中性灰辅助文字；取消按钮深色高光及暖色表面染色。日间弹窗使用白色表面，不再捕获背景位图或启用原生背景模糊。夜间与全屏播放浮层仍沿用原有深色材质。

全屏左半区上下滑动调整当前窗口亮度，右半区调整媒体音量；上滑增加、下滑减少，显示圆角百分比提示。参考 [VLC Android 官方手势说明](https://docs.videolan.me/vlc-user/android/3.X/en/video/video_player.html)。首次有效滑动锁定纵向 / 横向及起始侧，位移按起点计算，避免累积舍入误差。亮度最低 5%，音量使用系统媒体流上限，可降至静音，不做额外音频放大。

内嵌播放与画中画不启用纵向调节；原生时间轴与可点击控件优先接收触摸。选集及设置窗口维持独立触摸处理。多指、失焦、尺寸变化、切换会话会取消当前手势；退出全屏、进入画中画、后台及关闭播放页恢复原有窗口亮度。不会修改系统亮度或申请系统设置写权限。媒体音量与硬件音量键一样保留用户选择；固定音量设备及系统权限限制提供文字反馈。

新增设备测试覆盖亮度 / 音量上下限、横向抑制、非全屏禁用、取消、恢复及不误触跳转。播放器流程测试增加实际全屏左侧滑动与退出恢复断言。测试记录与日间截图存于 artifacts/v0.43.0/。

131 项单元测试及 debug lint 通过。11 项播放预取 / 稳定性设备回归通过：模拟慢网基线 1 次缓冲、预取 0 次；20 轮资源压力验证播放器创建与释放 52/52，播放器弱引用、媒体请求及换源请求全部归零。Java 堆采样约 8.8 / 8.4 / 8.1 / 8.0 MB，PSS 约 145 MB，未观察到持续增长。此结论限于已覆盖的模拟器测试，并非所有设备无泄漏的保证。
