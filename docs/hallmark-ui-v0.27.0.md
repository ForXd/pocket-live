# v0.27.0 Hallmark 界面整理

按用户指定安装并使用 [Nutlope/hallmark](https://github.com/Nutlope/hallmark) 2.0.0。范围为 Android 原生应用的首页、搜索结果、设置及共享控件；主题采用项目已有品牌色，不套用营销页布局或浏览器示意图。用户此前已确定固定顶部搜索、底部四项目的地、右下角设置、爱情/悬疑等题材、贴边海报及日夜模式，本次保持这些约束。

## 设计选择

- 材料：实际源站海报、片名、题材、评分、播放历史和应用状态。测试截图使用原有受控片库素材，不声称内置这些影片。
- 识别特点：贴边海报与片名构成主视觉，青绿只用于当前选择和主要操作。
- 首页：继续观看独立成区，豆瓣推荐标题位于其自己的筛选与影片上方；续播卡减少留白。
- 搜索：缩小外轮廓圆角，海报贴边，信息集中在右侧。筛选由大胶囊调整为较小圆角的原生标签，选中增加勾选图标；保留至少 48dp 的交互区域。
- 设置：外观、应用更新、来源广告规则使用文字行和方向图标，分隔线区分行；播放/网络、缓存设置保留可展开分组。所有原有动作和测试标识保留。
- 主题：沿用 Theme.kt 中的品牌色和系统字体。日间使用轻微绿调的浅底和中性内容表面，夜间保留深色层次；颜色不散落在业务组件里。
- 文案：搜索排序从附在文字后的 ↓ 改为独立图标；设置摘要的中点分隔改为逗号/斜线；影片元数据用空白区分。技术清晰度标记、许可证和风险说明保留原文，避免改变事实或安全含义。

计划自评：层级、执行、克制各 4/5，产品特异性 3/5；较弱处是通用设置页，因此只保留任务相关入口，不增加品牌装饰。不是独立评审评分。

## 原生验证边界

执行 `node ~/.codex/skills/hallmark/scripts/sloplint.mjs app/src/main/java/org/streampocket/HomeScreen.kt --scope app --render`，工具返回不支持 Kotlin（没有可读的 HTML/CSS/JSX 等文件）。因此不声称通过 Hallmark 网页 lint，也不生成替代网页冒充 App。CSS token、focus-visible、reduced-motion 等要求分别对应 Compose MaterialTheme、原生控件焦点/语义及 Android 动画时长设置。实际用 Gradle lint、设备测试和模拟器截图检查。

不删除文件、路由或组件树，不改业务处理，不改既有测试来迁就外观。基线截图位于 `artifacts/v0.27.0/before`；首页/设置基线来自 0.25.0，后续至本轮前这些视觉结构相同，题材搜索基线来自 0.26.0。实际新版本截图、评审和测试结果保存在同一忽略目录。
