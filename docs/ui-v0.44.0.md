# v0.44.0 卡片层次、观看进度与推荐简介

设计方向：浅灰背景托住白色卡片，黑色文字与克制的细进度线，让用户一眼看到看过哪集、看了多少。延续原有字号和圆角；夜间保留深色表面，不增装饰背景。

- 全屏纵向调节仅从左 25% / 右 25% 起手触发，中间 50% 不调亮度或音量。起手区域与方向锁定，拖入另一侧不切换功能；双击、长按及时间轴继续保留。
- 历史卡片及“分集进度”直接展开各集，不经更多菜单；继续观看按钮独立保留。分集下方统一细进度线，多来源记录仍可展开。删除保留在更多菜单。
- 历史条目、分集记录、来源记录、详情续播区、详情选集、内嵌 / 全屏选集共用 WatchProgress。普通 4dp，紧凑选集 3dp，圆角端点；文字辅助说明百分比或完成状态。播放器可拖动时间轴保持原生实现。
- 历史新增可选总时长，兼容缺少此字段的旧数据。未知时长不伪造百分比、不使用加载动画；直播不显示点播进度。播放完保留满进度，重播从头开始。过滤广告时进度与总时长保持原始时间轴口径。
- 推荐旧网页入口实际返回不含简介的页面；优先读取公开 JSON intro 并核对影片 ID，网页仅作备用。电影、电视剧均实测；不自动搜索第三方片源，不执行网页脚本。

验收关注：手机 / 大字号下卡片层次与进度可读性、一步展开与继续播放不冲突、中心滑动无调节、记录持久化及旧版兼容、外部简介失败可重试。

简介实测记录：原电影 / 手机网页均返回 200、长度 2950 的无简介页面；公开 API 对电影 1292052、电视剧 30313969 返回 402 / 410 字简介。当前热门推荐前三部 36689621、37100984、38360996 也均返回匹配 ID 的非空简介。模拟器受本机 Fake-IP DNS 影响，生产网络安全策略正确拒绝保留地址；在线设备测试仅在测试注入 Google 公共 DNS 返回的真实公网地址，未放宽生产 DNS 限制。结果和复现材料存于 artifacts/v0.44.0/。

功能设备测试覆盖：左右边缘调节 / 中央抑制，历史一步展开与继续 / 删除，新增时长持久化与无时长旧记录兼容，真实电影 / 剧集 API，500 集播放器面板、实际完成后记录满进度与重播归零，主要日间页面。单元测试 134 项通过。
