# v0.16.0 · JSON 订阅导入

## 使用与兼容

“订阅”页保留粘贴链接入口，增加“选择 JSON 文件”和“粘贴 JSON”。已有订阅时点击右侧加号展开添加区。文件选择采用系统 OpenDocument；选择器允许浏览所有文件类型，内容必须是支持的 JSON 配置，以兼容文件管理器对 JSON MIME 类型标记不一致的情况。

三个入口共用原有 SubscriptionParser，未改变解析规则：支持 LibreTV sources/liveSources、源数组、source-catalog baseUrl 目录、TVBOX sites/lives 中的直连源。兼容 UTF-8 BOM、注释和尾逗号；继续跳过不支持的 Spider、脚本与 XML 接口，并显示导入、跳过和超限数量。

本地文件流式读取，超过 2 MiB 即拒绝；空文件、错误 UTF-8、非法 JSON、过深嵌套和无可用源都不会修改现有配置。读取在 IO 调度器执行，解析在 Default 调度器执行，共用原有取消、替换任务和串行落盘事务。粘贴失败保留输入，取消关闭后清除输入；输入内容不进入 saved-instance-state。

## 保存与更新

- 本地订阅标为“本地 JSON”，菜单提供“重新选择 JSON 文件”。替换保留订阅 ID 和仍存在来源的启停状态，历史不变。
- 原 JSON 与文件 URI 不落盘，不获取持久文件权限，也不新增存储权限。解析后的来源正常保存在应用私有目录，因此原文件删除后仍能使用。
- 内部身份使用 `local-json:` 加原始内容 SHA-256，存储读取只接受严格的 64 位十六进制标识；不会把本地标识当 HTTP 地址请求。相同原始内容重复添加被拒绝；不同空白或 BOM 可能生成不同身份，可通过原订阅菜单更新来避免新增。
- 在线订阅继续使用原 URL 下载更新。本地文件不自动同步，来源使用 HTTP 时仍遵循现有 HTTP 开关。
- 沿用最多 20 个订阅、总计 300 个来源，以及每次 100 个点播 / 50 个直播来源限制。未添加外部脚本、加密配置或网页解析引擎。

测试使用合成数据，不打包任何订阅源。尚未覆盖所有厂商文件管理器和云盘文档提供器。
