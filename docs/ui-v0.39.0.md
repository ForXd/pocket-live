# v0.39.0 幕间设计实现

按用户确认的第二套「幕间」方案实现原生 Android Compose 界面：暖黑背景、米白主动作、衬线片名、开放列表和安静导航。此前红色主题的探索稿已被替换。

## 页面与适配

- 首页以品牌、搜索入口和推荐/分类/直播标签开场。推荐的类型、题材和排序集中在筛选面板，保留下拉刷新、分页、失败重试与回顶。手机三列海报，平板按可用宽度自适应。
- 搜索按需展开，保留键盘提交、清空、题材、排序、来源探测和其他站点结果。搜索结果采用开放图文列表。
- 详情依次呈现海报、片名、简介、线路/同名换源、续播与选集。支持简介展开、500 集定位与倒序；较宽屏幕采用海报/信息分栏，宽屏搜索可同时查看结果与详情。
- 历史突出最新观看项，其余记录采用紧凑行。分集与删除在每项菜单内；时间、来源、类型及清空操作集中在筛选面板。
- 订阅采用展开列表，添加链接、文件和 JSON 入口位于底部面板。宽屏将订阅和来源分栏，来源列表仍懒加载。
- 设置采用开放列表，保留外观、更新、播放与网络、缓存和来源广告路径规则。
- 全屏保留 Media3 时间轴和手势，采用米白进度及渐隐控制区；横屏选集按用户补充要求从右侧滑出半透明半屏面板，覆盖视频而不压窄画面；500 集可按每 50 集跳转并回到当前集。平板非全屏播放器展示常驻信息/选集侧栏。
- 840dp 起使用侧栏导航；较窄窗口和竖屏平板使用底部导航。日间、夜间、跟随系统、大字号仍可用。

## 视觉细节

字号统一为电影主标题 32sp、普通页面标题 26sp、区块标题 20sp、正文 16/14sp、辅助信息 12sp；字重收敛到 Medium。操作弹层标题也使用 20sp 无衬线。圆角按控件尺寸使用 8/12/16/20dp，搜索输入与占位文字共用正文样式，选集格保持同一高度。订阅时间使用明确的 yyyy-MM-dd HH:mm。详情长列表具有独立返回导航；集数列宽随可用空间调整，手机三位数集数完整显示。播放控件显示时以暗遮罩保证亮画面上的对比度。

全屏选集使用右侧半屏原生 Dialog，背景模糊由系统合成器执行，文字本身不模糊。半径为 24dp、最大 80px；暖黑底约 88% 不透明，避免视频背景干扰阅读。Android 12 以下或系统关闭模糊时回退为约 97% 不透明底。开关监听、窗口和 Compose 内容随面板释放；打开选集隐藏底下播放控件，不新建播放器或逐帧截图。

平台依据：[Android window blurs](https://source.android.com/docs/core/display/window-blurs)。模糊能力依赖设备和系统状态，始终保留清晰可读的回退样式。

## 性能与资源边界

业务模型、播放会话所有权和原有取消/释放逻辑保持。列表按稳定键懒加载；海报普通档限制 128,000 像素，大幅海报限制 512,000 像素，二者共用 6 MB 内存 LRU、20 MB 磁盘缓存及两个并发任务。下载仍限 1 MB、源图仍限 1600 万像素，后台生命周期取消图片请求。没有常驻视频预览、自动轮播或无限图片缓存。

界面图标取自 Lucide 0.468.0，按原路径转换 Android VectorDrawable，统一 1.75dp 描边；原始 SVG 与 ISC 许可证保存在 `third_party/lucide/`。影片海报来自用户启用的来源，设计稿素材不打包到正式应用。

## 验证

最终验证日志与截图位于 `artifacts/v0.39.0/final-ui/`，视觉对照见项目根目录 `design-qa.md`。正式发布使用 0.39.0（47）、原包名与原签名，通过公开附件验证及 0.38.0 应用内覆盖升级后记录结果。

模拟器测试能检查已覆盖路径的资源回收与堆趋势，不能据此宣称所有设备和来源绝无内存泄漏或不卡顿。

## 换源并发检测

按用户追加要求，播放器“快速换源”对匹配当前集的候选媒体地址进行最多 3 路并发检测。确认两个媒体可用后，取消剩余媒体读取、排队检测和未完成的候选来源搜索；可用项优先显示，界面显示检测状态与停止提示。每项 5 秒、整体 18 秒，候选地址去重且最多 40 个。

复用有界媒体探测：每次读取最多 64 KiB，检查媒体容器或 HLS 分片；加密/无法判定内容保留“待确认”，不算成功。该结果不替代实际设备解码能力验证，因此保留原有手动选择。检测当前集而非默认首集，保留进度换源逻辑不变。关闭窗口、退出播放、进入后台都会取消当前检测，旧会话结果不会覆盖新会话。
