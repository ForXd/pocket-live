# v0.39.0 影院式视觉优化

参考用户提供的影视应用界面，以近黑背景、红色操作强调和海报优先的层级整理原有 Android 界面。保留应用品牌图标、日间/夜间/跟随系统模式及全部功能。

- 夜间改用中性近黑与炭灰表面，日间使用暖白与深红；选中导航、筛选、播放入口统一强调色。
- 推荐与分类海报的标题底板融入页面，字号从 13sp 调整为 14sp，评分仍用金色和文字区分。
- 详情头部用当前影片海报铺设渐隐背景，前景保留完整封面与片名；播放、线路、集数、简介和换源逻辑不变。
- 播放器进度改为红色，缓冲为灰色、拖动点为白色，保持现有手势和控制布局。
- 保留原有页面切换、卡片按压及展开动画；没有加入轮播、演员、收藏等参考图中的额外功能，也没有打包参考图内的影片素材。

本地验证证据保存在 `artifacts/v0.39.0/`，设计过程保存在 `.oil-ui/cinema-v039/`。发布前核验 0.39.0（47）的原正式签名和应用内覆盖更新。

独立存量视觉评审（不打分）检查日夜主要页面，已按建议增强历史续播按钮、降低未选中标签强调。单线路禁用态保留。130 项单元测试通过，release lint 无错误、46 项既有警告；日夜正常字号与夜间两倍字号 UI 路径各通过。
