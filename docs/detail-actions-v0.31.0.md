# 0.31.0 紧凑浏览与详情操作

- 详情页采用轻量来源行：线路下拉与同名换源同排，去掉独立描边和等宽大按钮。倒序与集数定位放在选集标题行，吸顶和回顶行为保持。
- 固定续播条左侧显示集数与已观看时间，右侧为内容宽的播放按钮。保持至少 48dp 触控高度，长集名省略，不把集名塞入按钮。正常与两倍字号均保留可见播放入口。
- 推荐、分类搜索使用同样的横向筛选区域和右侧排序图标，分类来源和题材统一为浅色下拉按钮；保留多选、清除、全部来源默认搜索、排序和翻页行为。
- 顶部搜索外边距从上下各 8dp 改为 4dp；普通标题栏从 64dp 改为 56dp；底部导航正常字号从 80dp 改为 64dp，大字号仍为 80dp。保留系统安全区、导航选择语义和键盘出现时隐藏导航的逻辑。
- 沿用 Material 青绿日夜主题。参考 Oil UI 独立设计建议，并以实际正常、夜间、两倍字号截图检查视觉层级。

## 验证

API 37 模拟器，1080×2400、density 420。正常字号详情与页面操作 2 项、夜间详情 1 项、两倍字号详情 1 项通过；首页浏览、分类搜索、排序与更新器共 13 项设备回归通过。覆盖续播原集数、线路切换、500 集定位、倒序、同名换源、筛选、分页、回顶、键盘贴合与更新文件校验。
