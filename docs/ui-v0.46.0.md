# v0.46.0：展开来源后探测，保持探测与播放一致

## 行为

- 搜索列表以作品为单位展示。明确季数的系列合为一张卡，选季后点“查看来源”展开；同一时刻只展开 / 检测一个作品季。
- 来源检测最多 3 路并发，当前作品季找到 1 个 READY 后立即取消其余检测，成功来源在卡内优先显示绿点。收起、选其他季、切换类别、离开搜索或新查询会取消相关工作；失败时可手动播放或重试。
- 搜索结果仍保持用户排序，READY 不再把整个作品列表重排。来源超过 3 个时在限高列表中滚动。
- 精确片名规范化后，缺失年份 / 类型的来源只与唯一兼容且信息更完整的作品合并。明确不同年份、季数、版本名以及有歧义的未知记录不猜测归并。详情与历史原有严格身份规则保留，避免合并观看断点。
- 历史卡左滑最多露出 88dp 操作区，滑动本身不会删除；点击“删除”移除当前合并剧目的记录，其余剧目保留。原更多菜单与确认入口保留供非手势操作使用。
- 详情加载使用全尺寸容器居中显示 40dp 环形指示器、淡色轨道、状态文案和取消按钮。支持大字号，沿用当前主题。

## 3003 的复现与修正

受控测试媒体通过 `/play?token=fixture` 返回 HLS 清单，地址没有 `.m3u8` 扩展名。旧逻辑能检测到合法清单与 TS 头，但播放器按其他格式解析，实际复现 3003 且没有视频帧。`artifacts/v0.46.0/repro-red.log` 保留失败证据。

检测结果现在携带成功的原始剧集地址、线路名和 HLS MIME。详情优先展示检测成功的线路，实际播放将相同入口和格式交给 Media3 HLS，不会把子清单或 TS 切片地址当作影片入口。换源检测也保留相同格式信息。未经检测的无扩展名地址在播放前最多读取 4KiB、最多等待 5 秒以识别 HLS；识别任务随播放器停止取消，不创建额外播放器。

详情接口若刷新了带令牌的地址，则撤销旧 READY / 清晰度结论，保留线路选择，并对新地址重新识别；不会把旧 URI 的 MIME 检测结论套到新 URI 上。正常 MP4 和原生 `.m3u8` 播放路径保留。

测试中的“后会友期”为对应用户反馈设置的剧目标题，视频内容是仓库内可控媒体，不是该片的外部提供方。当前没有原始失败来源配置，不能据此声称该片所有外部来源已验证。READY 仍是有界清单 / 首切片检测，不是整片、所有编解码器或未来网络有效性的保证。
