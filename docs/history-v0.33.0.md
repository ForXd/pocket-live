# 0.33.0 观看历史与最近观看

方向：主页让用户接着看，历史页让用户找得到。沿用青绿 Material 主题，封面、标题、分集为主信息；来源、观看日期和断点为辅助信息。没有完整时长，不伪造百分比进度。

历史页固定关键词、时间范围、来源和点播/直播筛选区，查询按每条断点筛选后分组，展开只显示符合条件的集数。保留继续、分集、删除和清空确认。数据来自现有最多 100 条持久历史，不另建数据库或网络查询。

首页增加最近观看分区：横向分页卡片轻微重叠、缩放和淡化，相邻卡片提示横滑；仅预组合相邻页，海报复用缓存，点击继续前不创建播放器。大字号允许卡内垂直滚动。

分类与推荐分类选择窗仅把手拥有竖向拖动检测，内容滚动不拖动窗口。保留系统返回、取消、遮罩点击；手柄触控高度 48dp，下移达到 48dp 后关闭。

验证与正式升级记录待完成后补充。
