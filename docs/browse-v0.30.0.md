# 0.30.0 首页滚动与卡片调整

## 交互与布局

沿用现有 Android Material 风格，主角仍为影片。推荐页的类型、分类和排序，片库的来源、题材和排序，以及关键词搜索结果的题材和排序置于滚动区外，始终吸顶；搜索栏继续随上滑隐藏、下滑恢复。已选条件改为横向滚动的一行，避免多选后挤占整个内容区。

两列数量不变。按用户对留白的反馈，海报由 2:1 改为 3:4 竖版容器，使用居中裁切铺满卡片，不留两侧边、不加描边。较高容器减少竖海报的裁切；比例不同的原图仍有少量裁切。片名使用 13sp/17sp、统一两行及紧凑边距，长短标题底边对齐。相比上一版，本版优先保证更完整的竖版海报与常驻筛选区，不再用强裁图保证每种视口都容纳六张完整卡片。大字号继续跟随系统放大，按每行实际 sp 转换后的高度计算容器，兼容 Android 非线性字体缩放。搜索占位提示限一行，避免大字号撑高搜索栏。

- 接近底部自动请求下一页；同一结果边界只触发一次。单个请求未结束时不会重复提交，错误不自动重试，保留已显示的影片与位置。
- 推荐遇到全重复页停止翻页；片库无新增匹配结果时保留“继续查找”，避免自动扫描大量空页。已有页数/结果边界保留：推荐最多十页，片库最多 1000 条；“无限滚动”指无需逐页点击的连续加载，不承诺接口提供无限数据。
- 顶部下拉刷新推荐重新请求第一页；使用 Material 3 原生刷新指示器，刷新失败保留原结果。显式刷新按钮保留，方便无手势操作。
- 滚动一定距离后显示带语义标签的“回到顶部”按钮，平滑回顶并恢复搜索框。动画和观察任务绑定 Compose 生命周期；不启用后台轮询。
- 分页不再递增海报刷新代数，避免已显示海报重复重新加载。切换筛选/排序回到起点；离开片库页停止其自动翻页观察。

参考 Android 官方 [Pull to refresh](https://developer.android.com/develop/ui/compose/components/pull-to-refresh)。本轮为用户明确指定的局部调整，按 Oil UI 小改动规则进行主代理实际截图与手势自检，未启动独立设计评审。

## 验证

设备测试覆盖吸顶、两列卡片等高、自动翻页、重复页终止、错误保留及显式重试、回顶、真正下拉重新请求第一页、键盘打开时搜索栏固定。沿用题材/来源筛选、排序及布局回归。截图采用受控片库和测试海报，不代表内置片源。

发布目标 0.30.0 / versionCode 37；正式构建、签名与应用内升级结果在验收后补充。

开发回归曾发现混合字体标题高度差，已用固定两行槽修正并通过布局断言。公网豆瓣探测被当前代理 DNS 的保留地址拦截（`Local network blocked`），未放宽网络安全策略；受控推荐接口的加载、刷新与分页照常验收。
