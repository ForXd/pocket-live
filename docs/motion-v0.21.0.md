# v0.21.0 · 原生交互动效

## 设计与实现

采用 Jetpack Compose / Material 原生动画 API，参考 [Android 官方动画指南](https://developer.android.com/develop/ui/compose/animation/quick-guide)。

- 页面入场：220 ms、12 dp 上移淡入，搜索栏和底部导航保持不动。仅更新页面的图层，不同时组合两份页面，不增加请求或播放器实例；原有 rememberSaveable 状态与返回层级保持不变。
- 可点击卡片：按下缩至 98%，松手以无回弹振荡的 spring 恢复；与同一个 Material interactionSource 共享按压状态，保留原有水波纹、语义和点击区域。滚动取消按压后自然恢复。
- 设置分组：展开 220 ms、收起 180 ms，高度与淡入淡出同步；箭头在 0–180 度间旋转。
- 推荐与订阅分类：使用稳定内容键及 animateItem，让排序/新增/移除的位置变化可追踪。全源搜索维持原先不自动位移的策略，避免搜索流式返回时移动点击目标。
- 搜索：进度 180 ms 插值；清空按钮以宽度和透明度过渡，仍保留 48 dp 触控尺寸。
- 动画由 Compose 框架继承系统 animator duration scale，包含 0 倍。没有独立计时器、延迟点击或循环装饰动画。播放页不叠加页面转场。

- 系统动画 0 倍：主布局、搜索与返回、设置、继续观看流程测试通过。
- 手动控制 Compose 测试时钟，在展开 64 ms 后立即收起，确认内容完整移除；再次展开后开关可操作，测试通过。
- 840×1800、1.5 倍字体、动画开启的主布局测试通过，并检查设置页截图。
