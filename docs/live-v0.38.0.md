# 0.38.0 IPTV 直播入口

首页增加「直播」标签，复用唯一顶部搜索框和已有青绿 Material 组件。来源下拉选择已启用的 IPTV / M3U，按频道名称或 M3U group-title 本地搜索，并可选择分组；点击频道直接进入播放器。播放器直播返回按钮改为「返回频道」。没有来源时提供订阅管理入口，空频道、失败、重试和刷新分别显示。

单次只加载所选来源，不把同域名的不同直播清单合并；原配置保持。沿用网络安全检查与最多 500 频道解析上限，单项 22 秒超时，离开页面取消任务与 HTTP 请求。只缓存当前来源列表，切换来源替换；不按频道创建播放器或永久缓存页面。返回频道保留搜索、分组和列表位置，已有结果不重复请求。

M3U group-title / tvg-logo 可解析，但频道列表采用紧凑文字卡片，不为所有频道加载图片。没有添加内置直播地址、EPG 请求或未经验证的节目单。正常字号和深色两倍字号均实际查看截图；独立存量视觉评审通过（不打分）。

受控 M3U/HLS 设备路径覆盖：首页入口、顶部搜索、分组、真实视频出帧、返回资源释放、同域不同清单、刷新、失败重试入口、停用来源排除和离开取消。测试证明入口与受控媒体正常，不保证第三方频道随时可用。
